<h1 align="center">رسا پنل — Rasa Panel</h1>
<p align="center"><strong>مدیریت یکپارچهٔ کاربران، نودها و اشتراک‌های پروکسی</strong></p>
<p align="center"><a href="README.md">English</a> · <a href="#installation">نصب</a> · <a href="#features">قابلیت‌ها</a> · <a href="https://t.me/dev_vexel">پشتیبانی</a></p>

رسا پنل یک داشبورد چندزبانه برای مدیریت کاربران، زیرساخت چندنودی، لینک‌های اشتراک و آمار مصرف است. بک‌اند Python و API آن در کنار رابط React، مدیریت روی موبایل و دسکتاپ را با پشتیبانی فارسی، راست‌به‌چپ و تم روشن و تیره فراهم می‌کنند.

این پروژه نسخهٔ تغییر‌یافتهٔ PasarGuard 5.4.1 است. مجوز و انتساب توسعه‌دهندگان اصلی در [LICENSE](LICENSE) و [NOTICE](NOTICE) حفظ شده‌اند.

<a id="features"></a>
## قابلیت‌ها

| بخش | امکانات |
| --- | --- |
| کاربران | محدودیت حجم و زمان، ریست دوره‌ای، محدودیت دستگاه، قالب کاربر و عملیات گروهی |
| زیرساخت | چند نود، تنظیم هسته، لاگ نود و آمار مصرف |
| پروتکل‌ها | VLESS، VMess، Trojan، Shadowsocks، WireGuard و Hysteria2، بسته به پشتیبانی هسته و نود |
| انتقال | TLS، REALITY و تنظیمات قابل شخصی‌سازی هاست و اینباند |
| اشتراک‌ها | قالب کلاینت، لینک اشتراک، QR و خروجی سازگار با V2ray و Clash |
| مدیریت | چند مدیر، نقش‌ها و سطح دسترسی RBAC، کلید API و ابزار خط فرمان |
| اتصال‌ها | یکپارچگی تلگرام پنل، وبهوک و تنظیمات اعلان |
| رابط | فارسی و RTL، انگلیسی و ترجمه‌های همراه، تنظیم رنگ، تراکم و تم روشن/تیره |

در آپدیت رسا، صفحهٔ ورود، سربرگ منو، نمایش گزینهٔ فعال، کارت‌ها و عنوان صفحات بازطراحی شده‌اند. مسیرها و ابزارهای مدیریت حفظ شده‌اند. Docker رابط را مستقیماً از سورس می‌سازد و دکمهٔ راهنمای صفحات، تا زمان راه‌اندازی سایت مستندات، همین راهنما را باز می‌کند.

<a id="installation"></a>
## نصب روی سرور

به سرور لینوکس، Git، Docker Engine و افزونهٔ Docker Compose نیاز دارید. فایل Compose از شبکهٔ میزبان استفاده می‌کند؛ پورت انتخابی باید آزاد باشد. برای اتصال مستقیم HTTPS، گواهی معتبر دامنه و کلید خصوصی آن را آماده کنید.

```bash
git clone https://github.com/RasaPanel/panel.git
cd panel
cp .env.example .env
mkdir -p data/certs
```

زنجیرهٔ گواهی را در `data/certs/fullchain.pem` و کلید خصوصی را در `data/certs/key.pem` قرار دهید. این مقادیر را در `.env` تنظیم کنید:

```dotenv
UVICORN_HOST=0.0.0.0
UVICORN_PORT=8443
UVICORN_SSL_CERTFILE=/var/lib/rasa-panel/certs/fullchain.pem
UVICORN_SSL_KEYFILE=/var/lib/rasa-panel/certs/key.pem
```

```bash
docker compose up -d --build
docker compose exec rasa-panel python rasa-cli.py generate-temp-key
```

آدرس `https://YOUR_DOMAIN:8443/dashboard/` را باز کنید؛ به‌جای `YOUR_DOMAIN` دامنهٔ خودتان را بگذارید. از بخش راه‌اندازی مالک، با کلید موقت حساب مالک را بسازید. کلید موقت را خصوصی نگه دارید.

فرانت در مرحلهٔ مستقل Bun داخل Docker ساخته می‌شود؛ نصب Node.js یا Bun روی خود سرور لازم نیست. وابستگی‌های Python با فایل قفل uv نصب می‌شوند. ساخت نخست به دریافت وابستگی‌ها نیاز دارد. آپدیت سورس گیت‌هاب، نصب فعلی روی سرور را خودکار تغییر نمی‌دهد.

<a id="configuration"></a>
## تنظیمات

| مسیر یا متغیر | کاربرد |
| --- | --- |
| `.env` | تنظیمات سرور، دیتابیس و اتصال‌ها؛ از `.env.example` شروع کنید |
| `UVICORN_HOST` و `UVICORN_PORT` | آدرس شنود و پورت پنل |
| `UVICORN_SSL_CERTFILE` و `UVICORN_SSL_KEYFILE` | مسیر گواهی داخل کانتینر |
| `SQLALCHEMY_DATABASE_URL` | اتصال اختیاری به دیتابیس خارجی |
| `data/` | دیتابیس، گواهی‌ها و فایل‌های پایدار نصب |
| `interface/src/constants/Project.ts` | لینک سورس، پشتیبانی و مستندات اختیاری برند |

دیتابیس پیش‌فرض SQLite است و در `data/db.sqlite3` باقی می‌ماند. PostgreSQL/TimescaleDB، MySQL و MariaDB به دیتابیس آماده و قابل‌دسترسی با رشتهٔ اتصال async سازگار نیاز دارند؛ Compose همراه پروژه این دیتابیس‌ها را نصب نمی‌کند. متغیرهای قابل استفاده در `.env.example` آمده‌اند.

پس از تغییر برند رابط، تصویر Docker را دوباره بسازید. پس از تغییر `.env`، کانتینر را بازسازی کنید. اگر HTTPS را در reverse proxy خاتمه می‌دهید، آدرس شنود پنل و upstream پروکسی را متناسب تنظیم کنید. پروژه به‌صورت خودکار Nginx یا گواهی نصب نمی‌کند.

<a id="users"></a>
## مدیریت کاربران و دسترسی

1. هسته یا نود موردنیاز را متصل و وضعیت آن را بررسی کنید.
2. اینباندها و هاست عمومی مورد استفادهٔ کلاینت را تنظیم کنید.
3. کاربر را بسازید یا قالب کاربر اعمال کنید؛ حجم و تاریخ انقضا را تعیین کنید.
4. لینک اشتراک را در کلاینت سازگار آزمایش کنید.

برای مدیران از نقش‌ها و دسترسی محدود به منابع استفاده کنید. عملیات گروهی نیز مطابق همین دسترسی‌ها اجرا می‌شود. تنظیمات موجود پنل برای ریست دوره‌ای، دستگاه‌ها و قالب‌ها قابل استفاده‌اند.

<a id="nodes"></a>
## نودها و هسته‌ها

نود راه دور جداگانه نصب می‌شود. مشخصات اتصال را در پنل ثبت کنید و پیش از اختصاص ترافیک، وضعیت و لاگ آن را بررسی کنید. نام بسته‌ها و شناسه‌های فنی اصلی برای سازگاری حفظ شده‌اند؛ این مخزن توزیع مستقل نود رسا ندارد. فعال بودن پروتکل به نسخهٔ نود، هسته و تنظیم اینباند بستگی دارد.

<a id="subscriptions"></a>
## هاست‌ها و اشتراک‌ها

دامنهٔ عمومی، پورت، انتقال و مشخصات TLS/REALITY کلاینت در بخش هاست و اینباند تنظیم می‌شوند. HTTPS پنل و انتقال کلاینت تنظیمات جدا دارند؛ تغییر دامنهٔ ورود پنل، آدرس هاست‌های قبلی را خودکار عوض نمی‌کند. بعد از تغییر هاست، اشتراک را به‌روز و DNS و اتصال را از کلاینت بررسی کنید.

قالب کلاینت خروجی اشتراک را تعیین می‌کند. استفاده از دامنه به‌تنهایی آی‌پی مبدأ را پنهان نمی‌کند؛ دامنه همچنان به یک آدرس resolve می‌شود.

قالب پیش‌فرض صفحهٔ اشتراک، **Classic**، همان ظاهر اصلی پاسارگارد را دارد و از تم مدیریتی رسا مستقل است. برای فعال‌کردن آن در نصب قبلی، در `.env` مقدار `SUBSCRIPTION_PAGE_TEMPLATE="subscription/classic.html"` را قرار دهید. اگر `CUSTOM_TEMPLATES_DIRECTORY` دارید، فایل هم‌نام در آن پوشه بر قالب داخلی اولویت دارد؛ قالب سفارشی را پیش از جایگزینی حفظ کنید. این گزینه، ظاهر صفحهٔ وب اشتراک را تغییر می‌دهد؛ فرمت کانفیگ کلاینت و لینک‌های کاربران را تغییر نمی‌دهد.

<a id="updating"></a>
## آپدیت

ابتدا بکاپ بگیرید و [گزارش تغییرات](CHANGELOG.md) را بخوانید. اگر سورس محلی را تغییر داده‌اید، پیش از pull تغییرات را حفظ کنید.

```bash
git pull --ff-only
docker compose up -d --build
docker compose logs --tail=100 rasa-panel
```

آپدیت را از مخزن رسا دریافت کنید. اسکریپت نصب پروژهٔ اصلی، بسته‌های همان پروژه را نصب می‌کند. پس از مهاجرت دیتابیس، بازگشت صرفاً به تصویر قبلی ممکن است کافی نباشد؛ برای بازگشت، نسخهٔ سورس و بکاپ دیتابیس باید با هم سازگار باشند.

<a id="backups"></a>
## بکاپ و بازیابی

برای SQLite، در یک بازهٔ کوتاه نگهداری پنل را متوقف کنید تا دیتابیس و فایل‌های WAL به‌صورت سازگار ذخیره شوند:

```bash
docker compose stop rasa-panel
umask 077
mkdir -p backups
tar -czf "backups/rasa-$(date -u +%Y%m%d-%H%M%S).tar.gz" data .env
docker compose start rasa-panel
```

اگر آرشیو ساخته نشد، پنل را دوباره اجرا و خطا را پیش از آپدیت رفع کنید. یک نسخه از بکاپ را خارج سرور نگه دارید. آرشیو شامل تنظیمات و کلیدهای خصوصی است. برای بازیابی، پنل را متوقف کنید، آرشیو سازگار را در پوشهٔ پروژه برگردانید و نسخهٔ متناظر را اجرا کنید. دیتابیس خارجی به روش بکاپ و بازیابی مخصوص خودش نیاز دارد.

<a id="troubleshooting"></a>
## رفع خطا

| مشکل | بررسی |
| --- | --- |
| کانتینر اجرا نمی‌شود | `docker compose logs --tail=100 rasa-panel`، مسیر گواهی، متغیرها و پورت |
| پورت اشغال است | `sudo ss -lntp`؛ پورت آزاد انتخاب و آدرس ورود را اصلاح کنید |
| خطای گواهی | تطابق دامنه، کامل بودن زنجیره و مسیر فایل داخل کانتینر |
| دامنه باز نمی‌شود | رکورد DNS و دسترسی به پورت تنظیم‌شده |
| نود آفلاین است | نسخه، اطلاعات اتصال، شبکه و لاگ پنل/نود |
| کلاینت وصل نمی‌شود | شنود اینباند، هاست عمومی، پروتکل، انتقال و تازه‌سازی اشتراک |
| ظاهر قبلی دیده می‌شود | بازسازی تصویر، بارگذاری مجدد مرورگر و تازه‌سازی PWA |

گزارش دقیق بررسی‌ها در [VALIDATION.md](VALIDATION.md) است. ساخت production رابط موفق است، اما همهٔ تست‌های بک‌اند و بررسی سخت‌گیرانهٔ TypeScript بدون خطا نیستند. ساخت Docker Engine و ترافیک واقعی در این محیط آزمایش نشده‌اند.

<a id="development"></a>
## توسعه

برای توسعهٔ محلی به Python 3.14+، uv و Bun نیاز دارید.

```bash
uv sync --frozen
cd interface
bun install --frozen-lockfile
VITE_BASE_API=/ bun run build
cp build/index.html build/404.html
cd ..
uv run python -m alembic upgrade head
uv run python main.py
```

قبل از migration دیتابیس و محیط توسعه را تنظیم کنید. بک‌اند در `app/`، رابط و اتصال فایل‌های استاتیک در `interface/`، ابزار خط فرمان در `cli/` و تست‌ها در `tests/` قرار دارند. خروجی schema از `scripts/export_openapi.py` گرفته می‌شود. workflow انتشار GHCR در `.github/workflows/rasa-release.yml` است؛ اعلان‌های مخزن تلگرام تا تعیین ربات و مقصد مستقل غیرفعال‌اند.
